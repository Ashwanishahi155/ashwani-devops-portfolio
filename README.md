## 💻 Local Setup & Development

Run this portfolio locally in seconds with zero build steps:

### Option 1: Python HTTP Server
```bash
# Clone the repository
git clone https://github.com/Ashwanishahi155/ashwani-devops-portfolio.git
cd ashwani-devops-portfolio

# Start a local web server (Python 3)
python -m http.server 8080
```
Open your browser and navigate to `http://localhost:8080`.

### Option 2: Node.js `serve` / `npx`
```bash
npx serve .
```

### Option 3: VS Code Live Server
Simply install the **Live Server** extension in VS Code and click **"Go Live"** from `index.html`.
